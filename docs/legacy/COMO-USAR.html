siteaudit — como funciona e o que você precisa

Guia direto: o que a ferramenta faz, por onde ela passa para fazer, e exatamente o que instalar, configurar e pagar (spoiler: para o uso básico, nada).

Resumo em 30 segundos

Você dá um nicho e uma região. A ferramenta devolve uma lista de empresas com o site de cada uma diagnosticado e uma proposta de site novo pronta para mostrar.

1. DescobrirBusca empresas do nicho na cidade (Google Maps, Bing, DuckDuckGo, OpenStreetMap ou sua lista)
2. AuditarAbre cada site e extrai conteúdo, SEO, performance, design, tecnologia e contatos
3. GerarProduz o dashboard, o diagnóstico de cada site e a landing page de demonstração
Não precisa de chave de API para começar Não precisa de hospedagem. Não precisa de banco de dados. É um programa de linha de comando que roda no seu computador e cospe arquivos HTML/Markdown/CSV que você abre no navegador.

O que exatamente ela faz

1) Descobre empresas (leads)

Você informa nicho + cidade + UF. Ela consulta as fontes que você escolher e monta uma lista com: nome, telefone, endereço, site, categoria, nota no Google e nº de avaliações. Quem não tem site entra marcado como oportunidade — é a venda mais fácil que existe.

2) Audita cada site encontrado

Para cada site ela faz uma visita (como um visitante faria) e extrai:

Conteúdo
títulos (h1–h6), textos, listas de serviços, perguntas frequentes, contagem de palavras e os termos mais usados
SEO
title, meta description, canonical, sitemap.xml, robots.txt, HTTPS, dados estruturados (Schema.org), responsivo
Performance
tempo de resposta do servidor, peso da página, nº de requisições, arquivos que travam o carregamento, imagens pesadas
Design
paleta de cores (com teste de contraste), fontes, seções existentes, botões de ação (CTA), menu fixo
Tecnologia
WordPress, Wix, React, Elementor, Google Analytics, pixel do Meta, WhatsApp, chat, servidor/CDN…
Conversão
telefones, WhatsApp, e-mail, formulários, redes sociais, endereço, horários e mapa

Cada problema vira um achado com gravidade (crítico, alto, médio, baixo), explicação do impacto e a solução que você vai entregar. A soma deles gera uma nota de 0 a 100.

3) Gera o material de venda

Para cada empresa: um diagnóstico (o que está errado), uma proposta (landing page nova e moderna, montada com as cores, textos, fotos e WhatsApp reais do cliente) e um briefing em Markdown (o resumo para reconstruir o site em qualquer ferramenta).

Como ela faz (por dentro)

  • Consulta as fontes — cada provedor tem uma estratégia: o Bing e o DuckDuckGo são consultados por HTTP direto; o Google Maps e sites em JavaScript são abertos num navegador real (Chromium), porque o conteúdo só aparece depois que o JavaScript roda.
  • Normaliza e limpa — remove diretórios e redes sociais (um "site" que é só Facebook ou TripAdvisor conta como sem site), junta duplicados e completa dados faltantes cruzando as fontes.
  • Baixa cada site com educação: respeita o robots.txt, espera entre requisições e se identifica. Se a página voltar vazia (porque é feita em JavaScript), ela reabre no navegador automaticamente.
  • Extrai e diagnostica — parsing do HTML + CSS para conteúdo, SEO, design e tecnologia; medições de tempo e peso para performance; e uma bateria de regras que viram os achados.
  • Pontua — cada achado tem um peso por gravidade; a nota final vem de uma curva suave (não é um "zera tudo" artificial).
  • Escreve os arquivos — templates HTML/Markdown preenchidos com os dados extraídos.
    • Por que "scraping" e não uma API oficial? Porque APIs oficiais de busca não existem de graça. A ferramenta suporta as duas coisas: os provedores gratuitos (sem chave, mais frágeis) e a Google Places API (oficial, estável, precisa de cadastro). Você escolhe com a flag --providers.

    O que você precisa obrigatório / opcional

    ItemNecessidadeDetalhe
    Python 3.10+ obrigatório A linguagem que roda a ferramenta. Windows: baixe em python.org e marque "Add Python to PATH". Mac: brew install python3. Linux: já vem.
    Dependências Python obrigatório pip install -r requirements.txt — são 5 bibliotecas (cliente HTTP, parser de HTML, templates…). Nada pesado.
    Chave de API NÃO precisa Você consegue rodar tudo com os provedores gratuitos (Bing, DuckDuckGo, Google Maps via navegador, OpenStreetMap). A chave só entra se você quiser a rota oficial do Google.
    Navegador (Chromium) recomendado Só é necessário para: sites feitos em JavaScript, capturas de tela e o Google Maps. Instala com bash scripts/install_browser.sh (funciona mesmo sem senha de administrador).
    Google Places API opcional Rota oficial e estável. Veja o passo a passo abaixo. Só vale a pena se você for rodar muita busca por mês ou a partir de um servidor (VPS).
    Hospedagem / servidor NÃO precisa O resultado é arquivo estático. Para mostrar ao cliente você pode: abrir o HTML no seu computador, mandar o arquivo por WhatsApp/e-mail, ou — se quiser um link — arrastar a pasta para Netlify, Cloudflare Pages ou GitHub Pages (todos têm plano gratuito).
    Banco de dados NÃO precisa Os dados ficam em arquivos: leads.csv (planilha) e leads.json (completo).
    Cartão de crédito NÃO precisa A menos que você ative a Places API (o Google pede cadastro de pagamento para liberar, mas cobra só se passar da franquia gratuita).

    Como conseguir a chave da Google Places API opcional

  • Entre em console.cloud.google.com e crie um projeto (ou escolha um existente).
  • Vá em APIs e serviços → Biblioteca, busque Places API e clique em Ativar.
  • Vá em Credenciais → Criar credencial → Chave de API.
  • Restrinja a chave: limite ao Places API e, se possível, ao seu IP. Isso evita surpresas na fatura.
  • Habilite o faturamento na conta (o Google exige para liberar a cota, mas a franquia mensal cobre dezenas de milhares de consultas — para levantar algumas centenas de empresas por mês você normalmente fica no gratuito).
  • Use a chave:
    # Linux / Mac
export GOOGLE_MAPS_API_KEY="sua-chave-aqui"
python3 -m siteaudit run --niche "pizzaria" --city "Igrejinha" --state RS --providers places,maps

# Windows (PowerShell)
$env:GOOGLE_MAPS_API_KEY="sua-chave-aqui"

# ou passe direto no comando
python3 -m siteaudit run --niche "pizzaria" --city "Igrejinha" --state RS --providers places --places-key SUA_CHAVE
    • Alternativa sem chave e sem custo O provedor maps raspa o Google Maps com navegador — dá os mesmos dados (nome, telefone, endereço, nota) sem cadastro nenhum. Ele é mais frágil: o Google pode pedir CAPTCHA e costuma bloquear IPs de datacenter. Funciona bem no seu computador de casa/escritório.

    Instalação (3 minutos)

    # 1. entre na pasta
cd siteaudit

# 2. dependências básicas
pip install -r requirements.txt

# 3. navegador (opcional, mas recomendado)
bash scripts/install_browser.sh

# 4. confira
python3 -m siteaudit providers

    No Windows, use o PowerShell ou o Terminal do VS Code e troque python3 por python. Se o pip não for reconhecido, use python -m pip.

    Se o script do navegador falhar por falta de permissão, você não precisa dele para o básico — apenas não use --providers maps, --render nem --screenshots.

    Rodando

    O comando principal

    python3 -m siteaudit run --niche "pizzaria" --city "Igrejinha" --state RS \
    --providers bing,ddg,maps --limit 25
    FlagO que faz
    --nicheo ramo: "pizzaria", "contador", "advogado", "academia", "estética"…
    --city / --statecidade e UF da busca
    --providersfontes de dados: bing, ddg, maps, places, osm, google, manual
    --limitquantos leads por provedor (padrão 20)
    --max-auditlimite de sites a auditar (para testar rápido use 5)
    --screenshotssalva uma captura da home de cada site
    --renderusa navegador em todos os sites (mais lento e mais fiel)
    --fastpula a medição do tamanho dos arquivos (bem mais rápido)
    --delay 1.5pausa entre requisições — use se for raspar muita coisa

    Outros comandos

    # só descobrir empresas (sem auditar), exportando CSV
python3 -m siteaudit discover --niche "contador" --city "Novo Hamburgo" --state RS --providers maps --csv leads.csv

# auditar sites específicos
python3 -m siteaudit audit --url https://exemplo.com.br --city Gramado --state RS

# auditar uma lista de URLs (um por linha)
python3 -m siteaudit audit --file urls.txt

# usar sua própria lista de empresas (CSV/JSON)
python3 -m siteaudit run --niche "meus leads" --providers manual --file meus-leads.csv

# abrir o relatório no navegador
python3 -m siteaudit serve --dir relatorios/demo-completa
    Dica de ouro para o primeiro teste Comece pequeno: --limit 10 --max-audit 5. Assim você valida tudo em 1 minuto antes de sair varrendo 200 empresas.

    O que é gerado

    relatorios/<nicho>-<cidade>-<hora>/
├── relatorio-completo.html   ← ABRA ESTE (tem tudo num arquivo só)
├── index.html                ← dashboard com filtros (usa links entre arquivos)
├── leads.csv                 ← para planilha / CRM
├── leads.json                ← todos os dados, inclusive as auditorias
├── relatorios/<empresa>.html  ← diagnóstico detalhado de cada site
├── propostas/<empresa>.html   ← a landing page nova (sua demo)
├── briefings/<empresa>.md     ← briefing para reconstruir o site
├── sites/<empresa>.json       ← dados brutos extraídos
└── assets/<empresa>.png       ← capturas (com --screenshots)
    Qual arquivo usar com o cliente? Para apresentar: propostas/<empresa>.html (a demo) ou o relatorio-completo.html se quiser mostrar tudo de uma vez, inclusive em apresentações ou vídeos — ele não depende de mais nenhum arquivo, pode ser enviado por e-mail ou WhatsApp.

    Problemas comuns

    SintomaCausa e solução
    Abro o HTML e não vejo nada / os links não abrem Isso acontece quando o arquivo é aberto dentro de um visualizador isolado (iframe), onde os caminhos relativos entre arquivos não funcionam. Solução: abra o relatorio-completo.html — ele tem tudo dentro de um único arquivo, sem depender de pasta nenhuma.
    maps: lista de resultados não carregou Google pediu CAPTCHA ou bloqueou o IP (comum em servidor/VPS). Rode do seu computador, aumente --delay ou troque para --providers places (oficial) / osm.
    ddg: resposta bloqueada DuckDuckGo limita consultas seguidas. Espere alguns minutos, aumente o delay ou use bing.
    libnspr4.so not found Faltam bibliotecas do Chromium. Rode bash scripts/install_browser.sh.
    Site aparece com nota muito baixa mas carrega bem O site é todo em JavaScript. Use --render para abrir com navegador real.
    Muitos HTTP 403 A hospedagem do site bloqueia visitas automáticas. Nada a fazer pelo lado da ferramenta — ela registra como "Não auditado" e segue.
    Só aparecem diretórios e listas A busca web às vezes traz agregadores. A ferramenta já filtra os conhecidos (Guiamais, Telelistas, TripAdvisor, listas "melhores de…"). Combine com maps para ter dados de empresa de verdade.

    Limites e cuidados

    • Raspar buscadores fere os termos de serviço do Google e do Bing. Para operação comercial recorrente, prefira a Places API (rota oficial).
    • Telefone e e-mail são dados pessoais — no Brasil, trate conforme a LGPD: finalidade clara, contato proporcional e canal de opt-out.
    • A nota de performance é uma estimativa da própria visita, não um Lighthouse completo. Para propostas grandes, confirme com o PageSpeed Insights.
    • A detecção de tecnologia é por assinatura — pode haver falso positivo.
